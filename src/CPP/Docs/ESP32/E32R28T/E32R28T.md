# ESP32-2432S028R (CYD) — TFT_eSPI Setup Guide

> Board: **ESP32-2432S028R** ("Cheap Yellow Display" / CYD)
> Module: ESP32-WROOM-32E · Display: 2.8" 240x320 ILI9341 · Touch: XPT2046 (optional)
> Framework: **PlatformIO + Arduino**

---

## 🩺 What Was Causing the White Screen

A white screen means **backlight is ON**, but the **display controller never received valid init commands**.

Root causes found:

1. **Wrong Reset Pin** — `-DTFT_RST=-1` was used. On this board the LCD reset is wired to **GPIO 12**, not the ESP32's own reset. `-1` left the controller uninitialized.
2. **Missing Resolution** — `TFT_WIDTH` / `TFT_HEIGHT` were not defined, so the driver used defaults that didn't match the 240x320 panel.
3. **SPI Frequency Too High** — `40 MHz` was unstable. Dropping to **27 MHz** fixed signal-integrity issues.
4. **Stale Build Cache** — PlatformIO caches `build_flags`. A `clean` was required after editing `platformio.ini`.

## ✅ Correct `platformio.ini`

```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
monitor_speed = 115200

lib_deps =
    bodmer/TFT_eSPI@^2.5.43

build_flags =
    -DUSER_SETUP_LOADED=1
    -DILI9341_DRIVER
    -DTFT_WIDTH=240
    -DTFT_HEIGHT=320
    -DTFT_MISO=12
    -DTFT_MOSI=13
    -DTFT_SCLK=14
    -DTFT_CS=15
    -DTFT_DC=2
    -DTFT_RST=12
    -DTFT_BL=21
    -DTFT_BACKLIGHT_ON=HIGH
    -DSPI_FREQUENCY=27000000
    -DLOAD_GLCD
    -DLOAD_FONT2
    -DLOAD_FONT4
    -DLOAD_FONT6
    -DLOAD_FONT7
    -DLOAD_FONT8
    -DLOAD_GFXFF
    -DSMOOTH_FONT
```

## 📌 Pin Reference (ESP32-2432S028R)

| Signal    | GPIO | Notes                                       |
|-----------|------|---------------------------------------------|
| TFT_MISO  | 12   | Shared with TFT_RST on some revisions       |
| TFT_MOSI  | 13   |                                             |
| TFT_SCLK  | 14   |                                             |
| TFT_CS    | 15   |                                             |
| TFT_DC    | 2    |                                             |
| TFT_RST   | 12   | **Do not use -1**                           |
| TFT_BL    | 21   | Backlight, active HIGH                      |
| TOUCH_CS  | 33   | XPT2046 touch (optional)                    |

> ⚠️ On some revisions GPIO 12 is shared by `MISO` and `RST`.
> If you get a white screen, try `-DTFT_MISO=-1`.

## 🛠️ Setup Steps (Repeatable)

### 1. Create the project
```bash
pio project init --board esp32dev
```

### 2. Replace `platformio.ini`
Paste the configuration above.

### 3. Add a test sketch (`src/main.cpp`)

```cpp
#include <Arduino.h>
#include <TFT_eSPI.h>

TFT_eSPI tft = TFT_eSPI();

void setup() {
  Serial.begin(115200);
  delay(500);

  tft.init();
  tft.setRotation(1);              // Landscape 320x240
  tft.fillScreen(TFT_BLACK);

  tft.setTextColor(TFT_WHITE, TFT_BLACK);
  tft.drawString("Hello CYD", 10, 10, 4);
  tft.drawCentreString("Centered", 160, 60, 4);
  tft.drawNumber(1234, 20, 120, 4);

  Serial.println("TFT ready");
}

void loop() {}
```

### 4. Clean → Build → Upload
```bash
pio run --target clean
pio run --target upload
pio device monitor
```

### 5. Verify the USB port
The CYD has **two USB ports**:
- **Micro-USB** → usually the programming port
- **USB-C** → sometimes power-only

> If the upload "succeeds" but nothing appears, try the other port.

## 🔍 Troubleshooting Cheat Sheet

| Symptom              | Likely Cause                                    | Fix                                     |
|----------------------|-------------------------------------------------|-----------------------------------------|
| White screen         | Wrong `TFT_RST`, wrong driver, or bad SPI speed | `RST=12`, `ILI9341_DRIVER`, 27 MHz      |
| Black screen         | Backlight off                                   | Check `TFT_BL=21` + `BACKLIGHT_ON=HIGH` |
| Garbled / flickering | SPI too fast, bad wiring                        | Lower `SPI_FREQUENCY` to 20–27 MHz      |
| Upload OK, no output | Wrong USB port                                  | Try the Micro-USB port                  |
| Random colors        | Wrong driver (ST7789 vs ILI9341)                | Try `-DST7789_DRIVER`                   |

## 📚 Key Text-Drawing Functions

| Function                                    | Purpose                                |
|---------------------------------------------|----------------------------------------|
| `tft.drawString(str, x, y, font)`           | Draw text at X,Y (clears background)   |
| `tft.drawCentreString(str, x, y, font)`     | Center text at X                       |
| `tft.drawRightString(str, x, y, font)`      | Right-align text at X                  |
| `tft.setCursor(x, y)` + `tft.print(str)`    | Print at cursor (no background clear)  |
| `tft.drawNumber(n, x, y, font)`             | Draw integer                           |
| `tft.drawFloat(f, decimals, x, y, font)`    | Draw float                             |
| `tft.setTextColor(fg, bg)`                  | Set colors                             |
| `tft.fillRect(x, y, w, h, color)`           | Clear an area before redrawing         |

## 💡 Golden Rules

1. **Always `clean` after editing `platformio.ini`.**
2. **Never set `TFT_RST=-1` on the CYD.**
3. **Start at 27 MHz SPI** — increase only if stable.
4. **Use `drawString` over `print`** when values change, to avoid text overlap.
5. **Keep this file** — reuse it for every new CYD project.
